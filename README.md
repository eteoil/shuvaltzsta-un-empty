# シュバルツスタ-ʌ'n*empty-

8ビット風リズムバトルRPG（ブラウザゲーム）。上位文書は「アンエプ開発憲法 Ver.1.5」と「イベントデータ設計案 v0.3」。食い違ったときは憲法が優先する。ストーリーとエンディングの条件は「アンエプ プロット」が最新（Repsona の古いプロットは参考にとどめる）。

いまできていること：タイトル → 町（フェスト） → 会話 → リズムバトル（チャック＆ジッパー） → 決着 → 町、の1周。森（ダンジョン）には戦闘に勝たなくても入れる。フェストの駅から電車でラボと白夜砂漠の村へ行ける（どちらも中身はまだ無い）。フェストの銀行でお金を預けられる。

## 動かし方

`data/*.json` を `fetch` で読むので、ファイルを直接開く（`file://`）と動かない。静的サーバーで配る。

```sh
cd shuvaltzsta-un-empty
python3 -m http.server 8000
# → http://localhost:8000/
```

ビルドは不要。GitHub Pages などの静的ホスティングにこのフォルダをそのまま置けば公開できる。

## 操作

画面下のボタン（クリック・タップ）かキーボード。PC ではボタンの横に対応するキーが表示される。矢印キーで動かすなら左手で X・Z、WASD で動かすなら右手で K・J が A・B になる。タイトルでは START で PRESS START からメニューへ進み、NEW GAME を選ぶ。OPTION ではチートモードを切り替えられる（ポーズメニューからも切り替えられる。下の「チートモード」）。左上のランプはボタンを押している間だけ光る。

| ボタン | キーボード | 探索 | 戦闘 |
| --- | --- | --- | --- |
| 十字 | 矢印キー / WASD | 移動（上＝北東・右＝南東・下＝南西・左＝北西） | 移動（同じ） |
| A | X / K / Space | 話す・拾う（向き合って押す）・会話を送る | 隣の敵を攻撃 |
| B | Z / J | 会話を送る・店を出る | 回避 |
| PAUSE | P / Esc | ポーズ（アイテム・チート切り替え） | ポーズ（アイテム・チート切り替え） |
| START | Enter | ポーズ | ポーズ／結果を閉じる |

### 戦闘のルール

- 8×8マスの戦場を十字キーで自由に歩ける。歩くのに拍は関係ない。
- **A**：隣（斜めを含む8マス）にいる敵を攻撃する。何匹か隣にいるときは、目の前のマスの敵を最優先に殴る。拍ぴったりで押すとダメージとコンボ。拍から外れるとミス、隣に敵がいなければ「とどかない」。
- **B**：回避。敵の攻撃は数拍前に**床の赤いマス**で予告され、拍が近づくほど濃くなる。赤いマスに立ったまま、その拍で B を押すと避けられてコンボが伸びる。
- 赤いマスの外へ歩いて逃げても当たらない。ただしコンボは増えない。
- **紫のマス**は B では避けられない大技。歩いて範囲の外へ出るしかない。敵は隣に張り付かれたときだけ、この大技を選ぶ（続けては出さない）。
- 敵には向きがある。**背中や横から殴るとダメージ2倍**で、`GUARD` 中でも通る。敵は行動するたびにこちらへ向き直るので、そのすきに回り込む。
- 枠だけの赤いマスはフェイント。B を押すと空振りになり、コンボが切れる。
- 敵の頭上に `CHANCE` が出ている間は、その敵へのダメージが2倍。`GUARD` の間は正面からだと弾かれる。
- 1拍につき1アクション（A か B）。
- 下の帯は拍の目安。敵の攻撃が右から流れてきて、左端の線に重なった瞬間が拍。自分が範囲に入っている攻撃は大きく赤く表示される。少し明るい部分は「確定済み区間」（憲法⑮）で、ここに入った行動はもう変わらない。
- 勝つと「まいった」の会話 → リザルト → 戦闘後の会話、の順に進む。リザルトの SCORE は PERFECT・GOOD・最大コンボ・勝利ボーナス・残りHPから出し、係数は `gameConfig.json` の `battle.score`。戦闘ごとのスコアはプロットの「総スコア」として `session.totalScore` に足していき、そこからレベルが決まる（下の「レベル」）。
- 敵は距離と立ち回りを見て行動を変える。遠ければ近づき、張り付かれたら大技、回避ばかりならフェイント、攻撃ばかりならカウンターが増える（憲法⑤⑥）。

## お金・アイテム・NPC

- ポーズメニューの「時間を進める」で、◀▶ で1時間ずつ（1〜24時間）選んで時間を進められる（戦闘中とダンジョンでは使えない）。
- ポーズメニューの「アイテム」で持ち物を使う。戦闘中に使えば、その戦闘に効果が掛かる。コーヒー・ローリングスター・毒針などは戦闘中だけ使える。
- HP と毒は探索と戦闘をまたいで持ち越す。毒は探索中は2秒ごと、戦闘中は8拍ごとに減る（毒やアイテムでは倒れない）。会話中とポーズ中は減らない。負けたら（HP 0 で倒れたら）持っているお金が半分になり（端数は手元に残す。`gameConfig.json` の `faint.moneyKeepRate`）、「お金を半分なくした……」と出て、HP 満タン・毒なしで開始地点へ戻る（仮）。銀行に預けたお金は減らない。
- 戦闘中（ダンジョンでも）だけ使えるアイテム：コーヒー（攻撃がすべて PERFECT）・ローリングスター（回避が拍を少し外しても決まり、すべて PERFECT。回避の幅は GOOD の 90ms から 140ms に広がる。items.json の `dodgeWindowMs`）・毒針（2マス先まで届き、毒を与える）・パニックドロップ（2マス先まで届き、殴った敵を混乱させる）・痛み止め（受けるダメージと毒のダメージが半分）・ジャグジースペシャル（パニックドロップ・痛み止め・毒針のどれかの効果がランダムで出て、2倍の 64 拍続く。items.json の `durationRate`）。効き目は 32 拍。毒針の毒は 32 拍、パニックドロップの混乱は 24 拍続く（どちらも1回使うごとに、それぞれの敵を1回だけ。殴り続けても延びない）。
- 混乱した敵は、一番近いほかの敵に向かって攻撃する（チャック＆ジッパーならお互いを殴る）。その攻撃予告は黄色で、主人公には当たらない。ほかに敵がいなければ、うろつくだけ。混乱は確定済み区間の先の行動から効く（憲法⑮）。
- 毒針を使った敵は毒状態になり、距離を取ろうとする（憲法⑥）。ただしボス（敵データに `"boss": true`。チャック＆ジッパー）は逃げない。混乱しているあいだも逃げない（毒と混乱が両方効く）。
- 町には物は落ちていない（特別なイベントのときだけ、町のマップにも `pickups` を書く）。ダンジョンには野イチゴ・キノコ・毒消し草が落ちていて（森の出やすさは 5：3：2。マップの `pickups.table`）、そのマスに乗るか向き合って A で拾う。置き場所はランダムで、主人公・NPC・敵・出口の周り8マスには置かない。拾うと `field.pickupRespawnSec`（60秒）後に、別の場所へまた1つ現れる。
- フェストの通りには、シャルヴィスのカフェ（シャルヴィス・コウ）と、ジャグジーの薬屋への入口（床の菱形の枠）がある。中の人に向き合って A で話しかける。選択肢で B を押すと「なんでもない」を選んだのと同じになる。「買い物」「お弁当」を選ぶとお店の画面（SHOP）になり、十字で選んで A で買う。続けて何個でも買え、B で店を出ると会話も終わる。

  - コウ（カフェでくつろいでいる）：世間話・キノコ（持っているときだけ。鑑定して食用キノコか毒キノコに）・なんでもない。キノコを持っていなければ、話しかけるとすぐ世間話になる

- スライム液はダンジョンのスライムが落とす。使えないが、ジャグジーに1個 10$ で売れる。毒消し草と毒キノコも1個 50$ で売れる（items.json の `sell`）。毒消し草はジャグジーの店で 100$。

## 町とダンジョン

マップの `kind` で分かれる。

- **町**（`town`・フェスト）：探索の State（TOWN）。十字で歩き、A で話す。リズム入力は無い。
- **ダンジョン**（`dungeon`・森（深い森を含む）・監獄・奈落・砂漠・スラム）：入った瞬間から戦闘の State（DUNGEON）で（憲法③ Ver.1.5：リズム入力は戦闘とダンジョンだけ）、戦闘曲がループの頭から流れ続ける。戦い方は1対1の戦闘と同じ（拍に合わせて A で攻撃、B で回避、予告のマス、背中から2倍、毒）。
  - スライムなどのザコ（敵データに `aggro`）は、プレイヤーが `aggro`（4）マスより遠いとうろつき、近づくと寄ってきて攻撃する。倒すと消え、落とす物（敵データの `drop`。スライムはスライム液）をそのマスに残す。落とした物は拾っても置き直さない。
  - 森は入口から東へ進むと奥の空き地があり、オオカミが3匹いる（HP 80・近づくと寄ってくる距離 5 マス・移動が速い）。倒すとオオカミ肉（食べると最大HPの5%回復。シャルヴィスに1個 50$ で売れる）を落とす。オオカミは噛みつき（1拍前に予告）・飛びかかり（縦3マス）・大きく振り回す（まわり8マス）・フェイントを使い、毒のときは下がる。絵はコードで描いたドット絵（1ドット＝2px、64×48 ドットでスライムのおよそ2倍の大きさ）で、歩くとき（トロット・しっぽを振る）と攻撃するときにコマが動く（`core/Assets.js` の `drawWolf`）。
  - 隣に敵がいないときの A は、足元か目の前の物を拾う（拍の判定はしない）。
  - 監獄・奈落・砂漠：図書館のハルコールJr.（`data/npcs/harucall_jr.json`）に話しかけると、ひと言のあと監獄の檻（左上の小部屋）へ移る（選択肢の `travel`）。
    - 監獄（`prison_01`）：落ちている物は無い。看守（`data/enemies/guard.json`。HP 60・近づくと寄ってくる距離 4 マス。警棒の打ち下ろし・横なぎ（前3マス）・まわり8マスの避けられない叩きつけ・フェイント）が6人いる。看守は倒しても消えずに、座り込んで目を回した姿で残り（敵データの `faints`）、そのマスは通れない。いちばん奥（左下）に奈落への穴がある（出口の `hole`）
    - 奈落（`abyss_01`）：上から落ちてきて始まる（マップの `fallIn`）。少し進むと鬼灯（`data/npcs/hozuki.json`）がいて、話しかけると「ホヨヨ〜ン」という音を鳴らしながら、鬼灯が先に立って出口まで歩き、主人公はその後ろを自動でついて行く（NPC の `escort`。その間は操作できない）。出口の先は砂漠
    - 砂漠（`desert_dungeon_01`）：いまは仮にスライムとオオカミがいる。奥の出口から白夜砂漠の村へ出る
  - 深い森：森と同じマップ（`forest_01`）の東側にある、歩いては行けない場所。森の東の奥の空き地の端の崖（マップの `warps`。fall）に乗ると、暗くなって深い森へ移り、上から落ちてくる。マップは切り替わらないので、森と深い森でリザルトもスコアも分かれない。左上の名前と色味は、いる場所で変わる（マップの `areas`）。深い森は、落ちた所から上へ進むと奥の道に出て、その上側（北東）に城（`castle_01`）の入口がある。城の中にはマノロフ（`data/npcs/manorov.json`。絵は主人公の色替え、セリフは仮）。城を出ると城の前の道へ戻る。道は時計回りに右・下・左とぐるりと回っていて、最奥の崖（warps。slide）に乗ると、滑り落ちていつもの森の真ん中へ戻る。城に入るときは、ほかの出口と同じくリザルトが出る
  - スラム（`slum_dungeon_01`。フェストの南の道の先）：落ちている物は無い。スライムとゴロツキ（`data/enemies/gorotsuki.json`。HP 50・近づくと寄ってくる距離 4 マス。攻め方は看守と同じで、まわり8マスの叩きつけは無い。絵は主人公の色替え）が出る。ゴロツキは倒すと消える
  - 看守と鬼灯の絵は画像（`assets/img/guard_{ne,nw,se,sw,faint}.png`・`assets/img/hozuki_{ne,nw,se,sw}.png`）。いまの画像はコードで描いた仮の絵（1ドット＝1px、線も1ドット。`core/guardArt.js`・`core/hozukiArt.js`）を書き出した物で、画像が無いときはそのコードの絵を描く。看守は主人公と同じ大きさで、南西は前向き・北東は後ろ向き（南東・北西はその左右反転）と、気絶した姿。鬼灯は主人公の約1.2倍で、前向きとその左右反転だけ（後ろ姿は無い）

## 暦とお金

- 月を「節」、日を「区」と呼ぶ（例：火竜節5区）。1年は16節で、風剣季（春）・火錫季（夏）・地符季（秋）・水杯季（冬）に4節ずつ。節の名前は季ごとに竜・虎・鳥・亀（風竜・風虎・風鳥・風亀・火竜…水亀）。
- 1節は23区。16節（水亀節）だけ20区で、1年は365区。
- ゲームは聖誕祭ドー＝ヴ＝レンチ（風竜節1区）の3日後、風竜節4区の昼2時（地の雷刻）から始まる（白昼夢のような始まり方にするため）。日付は0時に変わる。暦のデータは `data/calendar.json`、数え方は `core/Calendar.js` だけが知っている。
- 行事：風竜節1区の聖誕祭「ドー＝ヴ＝レンチ」、水亀節20区の浄化祭「クイン＝ド＝レンチ」、23区ある節の最後の3区間（21〜23区）の天赦日（多くの人の休日）、水亀節の忌み月。その日にベッドで起きると一言出て、ポーズ画面の日付の下にも出る（`data/calendar.json` の festivals・restDays・tabooMonth）。
  - 天赦日：カフェが休み。シャルヴィスのお弁当とバイトの選択肢が出ない（選択肢の `closedOnRestDay`）。コウはカフェにいないで、フェストの東の端（図書館と森へ行く道の入り口）の前にいる（マップの npcs の `restDay`）。ザコの HP と攻撃力が 0.7 倍になり、ダンジョンで拾える物が2倍現れる（`gameConfig.json` の `restDay`）。薬屋も休みで、営業時間外と同じく入れない（マップの `closedOnRestDay`）
  - 祭りの日：世間話が変わる（選択肢の `sayOnFestival`）。ジャグジー「今日はお祭りだから特売だヨ！」、コウ「お祭りって美味しい食べ物がいっぱいで楽しいよね〜」、シャルヴィス「今日は祭りだからな……文字通り身を切った……」
  - 祭りの日：夜のバーのエレナに初めて話しかけると「今日みたいな日はめいっぱい楽しまなきゃね」でエーテル・小をくれる（祭りの日ごとに1回。NPC の `festivalGift`）
  - 祭りの日：シャルヴィスのお弁当にフライドドラコ（しばらく2秒・8拍ごとに最大HPの3%ずつ、27回回復）が並ぶ。1日5個まで、売り切れたら「今日の分は売り切れだ」（shop の `festivalItems` の3つ目の数）
  - 天赦日の前の日：シャルヴィスの世間話が「明日の豆は何にしようか……」から「明日の休みは何をしようか……」に変わる（選択肢の `sayBeforeRest`）
  - 祭りの日：ジャグジーの店が特売で3割引き（shop の `festivalSale`）
  - 忌み月：ザコの HP と攻撃力が 1.5 倍、落とす物が2個（`gameConfig.json` の `taboo`）。忌み月の祭り（水亀節20区のクイン＝ド＝レンチ）は、強さがふだんどおりで落とす物が3個（`taboo.withFestival`）
  - 祭りの日：落とす物が2個（`festival`）
  - 行事で強さが変わるのはザコ（敵データに `boss` の無い敵）だけ。町でもダンジョンでも同じで、ボス（チャック＆ジッパー）はいつも同じ強さ
- 時刻：町・ダンジョン・戦闘にいる間だけ、実時間1秒でゲーム内1分進む（会話中とポーズ中は止まる）。ベッドで眠ると、画面が暗転して休んだときのメロディが流れ、朝8時（天の泥刻）に起きる（0時より前に寝たら次の日の朝、0時を過ぎてから寝たらその日の朝）。数値は `gameConfig.json` の `time`（`wakeMinute` が起きる時刻）。バイトは3時間かかる。
- 時刻の書き方：天（午前）／地（午後）と、2時間ごとの陽（0・12時）・雷（2時）・炎（4時）・氷（6時）・泥（8時）・星（10時）。奇数の時は「半」を足し、分は「片」（例：3:00 は天の雷刻半、18:25 は地の氷刻25片）。ポーズ画面に、日付と時刻が数字つきで出る（例：風竜節4区(1/4)、地の雷刻(14:00)。数字は名前のすぐ後ろ）。
- 出口や扉を通るときは、足音（ザッザッザッ）が鳴って画面が暗くなり、着いた先で明るくなる（`gameConfig.json` の `field.fadeSec`、0.4秒）。戦闘やダンジョンから町へ戻ったときの会話とレベルアップの知らせは、明るくなりきってから出る。
- マップに入った直後は、十字キーをいったん離すまで歩き出さない（出口から出て、押したまま入り直さないように）。
- 夜（18時〜翌6時）：町が少し暗くなる。
- 営業時間（マップの `hours`）：
  - シャルヴィスのカフェ 15:00〜23:00。時間外はシャルヴィスとコウがいない（マップの npcs の `staff: true`。ベッドはいつでも使える）。夜（18時以降）は「シャルヴィスのバー」になり、あいさつが変わる（マップの `nightName`、扉の `nightLabel`、NPC の `nightGreet`）。バーの時間（18〜23時）はシャルヴィスの隣にエレナがいる（マップの npcs の `night: true`）
  - ジャグジーの薬屋 9:00〜17:00。時間外と天赦日は扉が閉まって入れない（扉の `closedText`）。中にいるうちに閉店したら、ジャグジーは「店じまい」と言う（NPC の `closedText`）
- お金の単位はバルツ（$）。1$ はだいたい10円（10$ で水のペットボトル1本くらい）。

## チートモード

タイトルの OPTION か、ポーズメニューの「チート」で ON / OFF を切り替える。戦闘中に切り替えても、その場から効く。設定はこのブラウザに覚えておく（セーブデータとは別）。ON の間は次のようになる。数値は `gameConfig.json` の `cheat`。

- 毒が `poisonTicks`（3）回ぶん減ったところで自然に治る（ふだんは毒消し草を使うまで治らない）
- HP が自動で回復する。探索中は `fieldRegenSec`（1）秒ごとに `fieldRegen`（1）、戦闘中は `battleRegenBeats`（8）拍ごとに `battleRegen`（4）
- 敵へのダメージ（攻撃と毒）が `attackMultiplier`（2）倍

## レベル

総スコア（`session.totalScore`）だけから決まり、レベルそのものはどこにも保存しない。数値は `gameConfig.json` の `level`。

- `scorePerLevel`（5,000）点ごとに1レベル上がる。最大 `max`（100）。Lv50 は 245,000 点、Lv100 は 495,000 点
- 憲法④（Ver.1.4）：レベルは総スコア（腕前の結果）からのみ上がる。撃破数や経験値では上がらない
- 1レベルごとに最大HPが `hpPerLevel`（5）増える（Lv1 で 100、Lv100 で 595）。上がったぶんは今の HP にも足す
- 戦闘後の会話のあとに「レベルが n に上がった！」と出る
- Lv `badEndAvoidLevel`（50）以上でバッドエンドを避けられる（エンディングはまだ無い。判定は `core/Level.js` の `avoidsBadEnd`）
- ポーズ画面の右上に今のレベルが出る
- 回復アイテムは最大HPに対する割合で回復するので、レベルが上がっても効き目の割合は変わらない

## 開発モード

URL に `?dev` を付けて開く（例：`http://localhost:8000/?dev`）。ポーズメニューに「レベル」「日付」「節」が出る。レベルは ◀▶ で1ずつ、A で10ずつ変えられる（100の次は1）。レベルは総スコアから決まるので、そのレベルになる総スコアに書き換える。日付は ◀▶ で1日ずつ、A で次の行事が始まる日（祭り・天赦日・忌み月。続く日は1日目）へ進む。「節」は ◀▶（A でも次へ）で1節ずつ、同じ区のまま進む・戻る（20区までの水亀節では20区に）。時刻は変わらない。祭りや天赦日の確かめに使う。チートモードとは別で、タイトルの OPTION には出ない。

## 戦闘の流れ

```
Pattern (JSON) ──敵AIが選ぶ──▶ EventTrack ──Sequencer が読む──▶ 挙動
```

1. 戦闘開始時に曲を予約し、その時刻を Beat 0 にする。
2. 毎フレーム、`AudioContext.currentTime` から現在 Beat を出す（出力遅延ぶん後ろへずらす）。
3. `Sequencer` が確定済み区間（現在 + `lookaheadBeats`）を進め、区間に入ったイベントは `prepare`（音の予約）、Beat を超えたものは `fire`（演出と判定の受付）。
4. 敵のイベント列の末尾が `現在 + lookaheadBeats + refillMarginBeats` より手前に来たら、敵AIが次の Pattern を選んで確定済み区間の先に足す。
5. `enemy.move` の移動先と、`enemy.attack` / `enemy.feint` の攻撃範囲は、確定済み区間に入った瞬間（`prepare`）に、その時のプレイヤーの位置から決める。以後は変えないので、予告されたマスがあとからずれることはない。
6. 入力は押した時刻でイベントと突き合わせる。拍の瞬間に攻撃範囲の中にいて、判定ウィンドウのうちに避けも逃げもしなかったら被弾。
7. どちらかの HP が 0 になったら、確定済み区間の先の小節頭に `system.finish` を載せる。`bgm.outro` は、そこから先で曲がアウトロへ自然につながる小節頭（`outroJoinBars`）に載せ、曲はそこで切り替わる。

EventTrack は `system`（`system.*` と `bgm.*`）が1本と、敵の一団ごとに `enemy:一団のid` が1本ずつ。一団は HP と敵AI と EventTrack を1つずつ持つ（1対1の戦闘は1つ。チャック＆ジッパーは2人で1つ。ダンジョンはスライム1匹ごとに1つ）。`fx.*` は Pattern に混ぜてよく、ゲーム性には影響しない。

## BGM

`data/gameConfig.json` の `bgm.battle`：

| キー | 値 | 意味 |
| --- | --- | --- |
| `startBar` | 1 | 戦闘開始時にここから鳴らす。1〜8小節目は READY までの前奏 |
| `loopFromBar` | 9 | ループの始まり（9小節目の頭＝9.142秒） |
| `loopToBar` | 25 | ループの終わり（25小節目の頭＝27.428秒）。16小節ぶん |
| `outroFromBar` | 25 | 決着後はここから最後まで流す（27.428秒〜） |
| `outroJoinBars` | [17, 25] | 決着後、ループ中のこの小節の頭まで待ってからアウトロへ移る |
| `offsetMs` | 23 | MP3 の先頭に入る無音（エンコーダ遅延）の補正。ふだんは読み込んだ曲から測った値を使い、測れなかったときだけこれを使う |

どれも「n小節目の頭」で数える。210BPM・4/4 なので1小節＝8/7秒。秒への換算は `Bgm.js` だけが行う。

ループは4小節ずつのまとまり（9〜12・13〜16・17〜20・21〜24）で、16小節目と24小節目はよく似た「つなぎの小節」になっている（小節ごとの音の似かたを測って確かめた）。なので25小節目のアウトロへは、24小節目のあと（＝25小節目の頭）だけでなく、16小節目のあと（＝17小節目の頭）からでも自然につながる。決着してからアウトロまでは最長8小節（約9秒）待つ。その間にリザルトが出て、アウトロが鳴り終わるまでは閉じられない（「A：つぎへ」は鳴り終わってから出る）。

`startBar` を 9 にすると前奏を飛ばしてすぐ戦闘になる。MP3 の頭の無音は、ブラウザによってデコード後に残ったり取り除かれたりする（Chromium では約23ms残る）。固定値だとずれたブラウザでアウトロへの切り替えが遅れ、次の小節の頭が一瞬聞こえてしまうので、`Bgm.js` が読み込んだ曲の頭の無音をその場で測って合わせる。

## 足し方

- **敵の行動を増やす**：`data/patterns/` に JSON を足し、敵の `patterns` に id を書く。`tags` の `approach` は3マス以上離れているとき、`basic` は通常、`feint` は回避が多い相手、`counter` は攻撃が多い相手、`rush` は2マス離れているときや敵の HP が少ないときに選ばれやすい。攻撃の範囲は `payload.area` に `front1`（正面1マス）/ `front3`（正面の横3マス）/ `line3`（正面へ3マス）/ `around`（周囲8マス）/ `around2`（周囲2マスまで）で書く。`"dodgeable": false` を付けると B で避けられない攻撃（紫のマス）になる。`tags` の `heavy` は、プレイヤーが隣にいるときに選ばれやすい。`retreat` は毒のとき（ボス以外）、`wander` は `aggro` より遠いときに選ばれる。`payload.actor` を省くと「その一団の1人目」になるので、スライムのような1匹の敵は同じ Pattern を何匹でも使い回せる。`enemy.move` に `"wander": true` を付けるとでたらめな向きに1歩、`"away": true` で離れる1歩。
- **アイテムを増やす**：`data/items.json` に足す。効果は `heal`（数字なら回復量、[分子, 分母] なら最大HPに対する割合）・`regen`（`rate` の割合ずつ `ticks` 回、しばらく回復する。間隔は gameConfig の `status.regen`）・`damage`・`poison`・`cure`・`buff`（`beats` 拍のあいだ効く）・`outcomes`（使うまで中身が分からない）の組み合わせ。どれも無い物は使えない（「使い道がない」）。`sell` に値段を書くと、ジャグジーの鑑定で売れる（シャルヴィスの食材は、NPC の buy の `prices` に書いた物だけを買い取る）。`buff` は `perfect` / `sway`（`dodgeWindowMs`）/ `needle`（`reach`・`poisonBeats`）/ `panic`（`reach`・`confuseBeats`）/ `guard`（`damageRate`）。使ったときのメッセージは「（名前）を `useVerb`」（食べた・飲んだ・装備した。無ければ「使った」）と `useText`、`outcomes` で選ばれたときのメッセージは `outcomeText`（`{name}` が選ばれたアイテムの名前）。
- **拾える物を変える**：ダンジョンのマップの `pickups` の `count`（同時に落ちている数）と `table`（`[アイテム, 重み]` の並び。重みが大きいほど出やすい）。置き場所は空いている床からランダムに選ぶ。
- **ダンジョンを増やす**：`data/maps/` に `kind: "dungeon"` のマップを足し、`spawns`（`{ enemy, at }`）に敵を置き、`exits` で町とつなぐ。`tint` で床の色味を変えられる。ダンジョンの `npcs` には、話しかけると出口まで連れて行ってくれる NPC（`escort: { sound }`）を置ける。出口に `hole: true` を付けると穴の絵になる。`fallIn: true` のマップは主人公が上から落ちてきて始まる。`warps`（`{ at, to: [i, j, 向き], label, fall | slide }`）は同じマップの中の別の場所へ移るマス（崖）。`areas`（`{ name, from, to, tint }`）で、場所ごとに左上の名前と色味を変えられる。
- **町の内装**（カフェ）：マップの `heights`（`floor` と同じ並びの数字。1＝`stepH` ドット）で床に高さを付けられる（ロフトと階段）。高さが1段（`stepH`）より違うマスへは歩いて行けない。`loftH` 以上のマスはロフトの箱（手前の面は `loftFront` の並び：`backbar`・`vitrine`・`panel`）、それより低いマスは階段の段になり、低い隣との縁に手すりが付く。`floor` の `-` は床を描くが歩けないマス（カウンターの内側）。`stairAxis`（'i' か 'j'）は階段の段が並ぶ向き。出口に `edge`（向き）を付けると、乗っても出ず、そのマスからその向きへ進もうとしたときに出る。`props`（`{ art, at, size, key, blocks, across }`）は家具で、奥から順に人と一緒に描く（`key` で順番を決められる）。`blocks: false` なら通れる、`across: true` ならその向こうの人に話しかけられる（椅子とカウンターが続けば、その先まで）。`wallArt: "cafe"` で壁の絵がカフェになり、`extraWalls`（`{ side, at: [i, j], style, start, end }`）で1行目・1列目のほかのマスの縁にも壁を立てられ、`walls` の並びの `null` の所には壁を立てない。`neWallTop` で右奥の壁（`walls.ne`）だけ低くできる。`wallDecor`（`{ side, at, style, flag }`。`at` は数か [i, j]）で壁に物を掛けられる（`flag` が立つまで出ない）。NPC の `sit`（座面の高さ）で座らせられる（腰から下を描かない）
- **クエストを増やす**：`data/quests/` に JSON を足し（`name`・`summary`・`need`（集める物と数）・`offer`（頼まれる会話と、受ける／受けない）・`waiting`・`deliver`（渡すか聞く・はい・いいえ・`reward` のお金とスコア）・`done`）、NPC の `quest` にその id を書く。会話の各行は `{ speaker, text }` で、speaker を変えるとほかの人のセリフにできる。受けたクエストはポーズメニューの「クエスト」に、受注中／完了と集めた数が出る（`session.quests`）。
- **NPC を増やす**：`data/npcs/` に JSON を足し、マップの `npcs` に置く。選択肢は `say`・`shop`・`appraise`・`trade`・`buy`（買い取り。`prompt` の `{price}` が値段になる）・`job`（`tired` は同じ日の2回目のセリフ）・`rest`（ベッド。`say` の `{date}` が日付になる）のどれか。どれも無い選択肢は会話を終える。`if.has`（と `if.count`）で持ち物がその数以上あるとき、`if.sellable` で売れる物を持っているときだけ出す選択肢にできる。`sprite` の代わりに `object`（いまは `bed` と `atm`）を書くと家具になる。`hideName` を付けると頭の上に名前を出さない（並んだ出納機）。`hidden` を付けると絵を描かない（壁の奥の窓口。床の外の壁の奥のマスに置き、手前のマスから話しかける）。`hours`（[開く, 閉まる] の分）を付けるとその時間の外は `closedText` だけ言う。`say` を文字の並びにすると順に言う（プレストの説明）。`travel`（`to`・`spawn`・`say`）で電車に乗って別のマップへ行ける。`bank`（`deposit` か `withdraw`）で出納機になる（セリフは NPC の `bank`。`ask` の `{step}`・`{bigStep}` は金額の刻み、`done` の `{amount}`・`{balance}` は動かした額と残高、あいさつの `{balance}` は残高）。出せる選択肢が1つだけなら、話しかけるとすぐそれが始まる。`trade.giveCount` で渡す個数を決められる。`trade.prompt` の `{price}` は値段になる。
- **敵を増やす**：`data/enemies/` に JSON を足し、町のマップの `encounters`（1対1の戦闘）か、ダンジョンの `spawns` から呼ぶ。見た目は `sprite` と `palette`（色の置き換え表）で決まる。`"boss": true` なら毒でも逃げない。`aggro` を書くとザコになり、その距離より遠いとうろつく。
- **調整する**：テンポ・判定幅・ダメージ・先読み拍数・戦場の広さ・歩く速さは `data/gameConfig.json`。
- **モーション**：`tools/animate_sprites.py` が静止チップを上半身・左脚・右脚に割り、ずらして歩き（4コマ）・走り（4コマ）・攻撃（3コマ）・回避（3コマ）のシートを作る。1コマの動きはスクリプト内の `MOTIONS` で調整する。手描きのコマができたら、`assets/img/an_{モーション}_{向き}.png` を同じ並びのシートで置き換えればよい（`data/sprites.json` の `anims`）。
- **ドット絵を差し替える**：`art/reference/` の画像を差し替えて `python3 tools/extract_sprites.py`（要 Pillow）。画像が無い間は仮の絵で動く。タイトルの線画（`title.png`）は、縮小率・2値化の濃さ・消す範囲（手描きのメニュー文字）をスクリプト内の `TITLE` で調整する。

ブラウザのコンソールで `game` を見ると、今の State・EventTrack・敵AIの選択履歴を覗ける。
